## ⚠️ 2026-11 更新：搜索接口已迁移

`https://aion2.plaync.com/api/search/character` 已下线（302 → 404）。
通过分析韩服官网角色搜索页（`ko-kr/characters/index`）的 JS，搜索服务已迁移至独立搜索域名，**新接口**：

```
https://api-search.plaync.com/aion2/search/v2/character?keyword=FO&race=1&serverId=1001&page=1&size=30
```

- 参数：`keyword` / `race`（1天族 2魔族）/ `serverId`（可选）/ `page` / `size`
- 请求头：需带 `Referer: https://aion2.plaync.com/`
- 返回结构不变：`{ list: [{ characterId(URL编码Base64), name(HTML), race, pcId, level, serverId, serverName, profileImageUrl }] }`
- 注意：`/aion2global/search/v2/character` 是全球服（region: naw/nae/eu/la/as），韩服国内站用 `/aion2/search/v2/character`
- `info` / `equipment` 接口仍然有效（`lang=ko`），characterId 直接传搜索返回的 URL 编码值即可，不要二次编码

本站代理接口：`/api/aion-kr/search`、`/api/aion-kr/info`、`/api/aion-kr/equipment`

## 🌍 2026-11 新增：国际服（全球服 / Steam）接口

国际服官网页面：`https://aion2.plaync.com/en-us/characters/index`，分 5 个大区：

| region 参数 | 中文 |
| --- | --- |
| naw | 北美洲西部 |
| nae | 北美洲东部 |
| eu | 欧洲 |
| la | 南美洲 |
| as | 亚洲 |

### 1. 搜索

```
https://api-search.plaync.com/aion2global/search/v2/character?keyword=FO&region=naw&localeInfo=en-US&race=1&serverId=1203&page=1&size=30
```

- `region` 与 `localeInfo`（en-US）**必填**，缺失返回 400
- `race`（1天族 2魔族）、`serverId`（可省略=全服）可选
- 返回结构：`{ list: [{ characterId(URL编码Base64), name(HTML), race, pcId, level, serverId, serverName(英文), profileImageUrl }] }`

### 2. 详情 / 装备

```
https://aion2.plaync.com/api/character/info?lang=en-US&region=naw&characterId=xxx&serverId=2203
https://aion2.plaync.com/api/character/equipment?lang=en-US&region=naw&characterId=xxx&serverId=2203
```

- ⚠️ 与韩服不同：必须带 `region` 参数，`lang` 使用 `en-US` 格式，否则 404

### 3. 服务器列表

```
https://aion2.plaync.com/en-us/api/gameinfo/servers?lang=en-US&region=naw
```

- 官方 serverId：天族 1101-1510、魔族 2101-2510（前两位数字标识大区）
- 各大区服务器英文名相同（Siel/Triniel 等），靠 serverId 区分

### 4. 本站偏移 ID 规则（避免与台服/韩服冲突）

- 国际服入库统一使用 `真实 serverId + 20000`：天族 21101-21510、魔族 22101-22510
- 韩服偏移：+10000（天族 11001-11021、魔族 12001-12021）
- 本站代理接口：`/api/aion-global/search`、`/api/aion-global/info`、`/api/aion-global/equipment`
- 服务器中文名对照见 `app/utils/aionGlobalServers.ts`
